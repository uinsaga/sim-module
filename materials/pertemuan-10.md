# 1. Capaian Pembelajaran

Setelah mempelajari modul ini, mahasiswa mampu:

- Memahami konsep Sistem Informasi Manajemen (SIM) dalam bidang Public Relations (PR).
- Menjelaskan fungsi media monitoring dalam dunia komunikasi modern.
- Memahami proses crisis management (manajemen krisis).
- Mengidentifikasi peran media sosial dalam pembentukan opini publik.
- Menganalisis kasus krisis komunikasi menggunakan pendekatan SIM.
- Menggunakan data dan informasi untuk pengambilan keputusan komunikasi.

---

# 2. Pendahuluan

Di era digital, informasi menyebar sangat cepat.

Satu postingan media sosial dapat:

* menaikkan citra lembaga,
* atau justru menghancurkan reputasi dalam hitungan jam.

Karena itu, bidang Public Relations (PR) membutuhkan:

* sistem informasi,
* data real-time,
* monitoring media,
* dan strategi komunikasi krisis.

---

# 3. Apa Itu Sistem Informasi Manajemen (SIM)?

## Definisi

Sistem Informasi Manajemen (SIM) adalah:

> sistem yang digunakan untuk mengumpulkan, mengolah, menyimpan, dan menyajikan informasi guna membantu pengambilan keputusan.

---

# Contoh Sederhana

Bayangkan sebuah universitas memiliki:

* akun Instagram,
* website resmi,
* YouTube,
* media partner,
* berita online.

Setiap hari muncul:

* komentar mahasiswa,
* berita media,
* opini masyarakat,
* kritik,
* dan isu viral.

Tanpa sistem informasi:
- data berantakan
- sulit dianalisis
- keputusan lambat

Dengan SIM:
- data terkumpul
- opini publik bisa dipantau
- pimpinan bisa mengambil keputusan cepat

---

# 4. Apa Itu Public Relations (PR)?

Public Relations adalah:

> kegiatan membangun hubungan baik antara organisasi dengan masyarakat.

---

# Tugas Public Relations

| Tugas PR                | Contoh            |
| ----------------------- | ----------------- |
| Membangun citra         | Branding kampus   |
| Menyebarkan informasi   | Press release     |
| Menjaga reputasi        | Klarifikasi isu   |
| Menangani krisis        | Respon saat viral |
| Menjalin hubungan media | Konferensi pers   |

---

# 5. Hubungan SIM dan Public Relations

SIM membantu PR dalam:

| Fungsi                | Penjelasan                       |
| --------------------- | -------------------------------- |
| Mengumpulkan data     | Komentar, berita, trending topic |
| Monitoring media      | Memantau opini publik            |
| Analisis sentimen     | Positif / negatif                |
| Pelaporan             | Statistik engagement             |
| Pengambilan keputusan | Strategi komunikasi              |

# 6. Media Monitoring

# Apa Itu Media Monitoring?

Media monitoring adalah:

> proses memantau, mengumpulkan, dan menganalisis informasi dari berbagai media.

---

# Tujuan Media Monitoring

- Mengetahui opini publik
- Mengetahui isu viral
- Mengukur citra organisasi
- Mengidentifikasi hoaks
- Mengetahui respon masyarakat

---

# Sumber Media Monitoring

| Media         | Contoh               |
| ------------- | -------------------- |
| Media sosial  | Instagram, TikTok, X |
| Portal berita | Detik, Kompas        |
| TV & radio    | Talkshow, berita     |
| Forum online  | Facebook group       |
| Website       | Blog, artikel        |

---

# Contoh Dunia Nyata

## Kasus

Sebuah kampus dituduh:

> “uang UKT naik tanpa transparansi”

Mahasiswa mulai:

* membuat thread di X,
* membuat video TikTok,
* menyebarkan poster digital.

Jika kampus tidak melakukan monitoring:
- isu semakin besar
- opini publik negatif
- reputasi turun

---

# Solusi dengan SIM

Tim PR menggunakan:

* dashboard monitoring,
* analisis hashtag,
* laporan sentimen publik.

Mereka menemukan:

* mayoritas mahasiswa bingung,
* bukan marah soal kenaikan,
* tetapi kurang transparansi.

---

# Keputusan PR

PR kemudian:
- membuat konferensi pers
- membuat infografik transparansi
- membuka sesi tanya jawab online

Hasil:

* isu mulai mereda,
* opini publik membaik.

---

# 7. Komponen Media Monitoring

# A. Data Collection

Mengumpulkan data dari:

* media sosial,
* berita,
* komentar,
* polling.

---

# B. Data Analysis

Menganalisis:

* jumlah komentar,
* sentimen,
* kata yang sering muncul.

Contoh:

| Kata         | Frekuensi |
| ------------ | --------- |
| UKT          | 1200      |
| Transparansi | 800       |
| Mahal        | 950       |

---

# C. Reporting

Hasil analisis dibuat laporan.

Contoh:

* grafik sentimen,
* jumlah engagement,
* trending topic.

---

# D. Decision Making

Pimpinan menentukan strategi komunikasi.

---

# 8. Analisis Sentimen

Analisis sentimen digunakan untuk mengetahui apakah opini publik:

| Jenis   | Contoh                  |
| ------- | ----------------------- |
| Positif | “Kampus cepat merespon” |
| Negatif | “Tidak transparan”      |
| Netral  | “Ada pengumuman baru”   |

---

# Contoh Sederhana

Komentar:

```text id="1nkrpn"
“Admin kampus cepat menjawab pertanyaan mahasiswa.”
```

Sentimen:
- Positif

---

Komentar:

```text id="qj3g2j"
“Informasi kampus membingungkan dan lambat.”
```

Sentimen:
- Negatif

# 9. Crisis Management (Manajemen Krisis)

# Apa Itu Krisis?

Krisis adalah:

> situasi yang dapat merusak reputasi organisasi dan membutuhkan penanganan cepat.

---

# Contoh Krisis

| Krisis               | Contoh               |
| -------------------- | -------------------- |
| Viral negatif        | Video dosen viral    |
| Hoaks                | Berita palsu         |
| Kesalahan komunikasi | Statement ambigu     |
| Kebocoran data       | Data mahasiswa bocor |
| Konflik internal     | Demo mahasiswa       |

---

# Kenapa Krisis Berbahaya?

Karena di era digital:

```text id="ppjlwm"
Informasi buruk menyebar lebih cepat daripada klarifikasi.
```

---

# 10. Tahapan Crisis Management

# A. Deteksi Krisis

PR harus cepat mengetahui masalah.

Caranya:

* media monitoring,
* keyword tracking,
* hashtag monitoring.

---

# B. Analisis Krisis

Pertanyaan penting:

* Apa penyebabnya?
* Seberapa besar dampaknya?
* Siapa yang terdampak?

---

# C. Respon Krisis

PR harus:
- cepat
- jelas
- transparan
- tidak emosional

---

# D. Evaluasi

Setelah krisis selesai:

* evaluasi strategi,
* analisis kesalahan,
* perbaiki SOP.

---

# 11. Studi Kasus Nyata

# Kasus 1 — Viral Video Pelayanan Buruk

## Situasi

Video pelayanan kampus viral di TikTok.

Isi video:

* mahasiswa dimarahi staf,
* video mendapat 2 juta views.

---

# Dampak

- reputasi kampus turun
- komentar negatif meningkat
- media mulai memberitakan

---

# Langkah PR

## Tahap 1 — Monitoring

PR memantau:

* hashtag,
* komentar,
* berita online.

---

## Tahap 2 — Analisis

Ditemukan:

* masalah utama bukan video,
* tetapi pelayanan yang lambat.

---

## Tahap 3 — Respon

Kampus:
- meminta maaf
- menjelaskan kronologi
- memperbaiki sistem pelayanan

---

## Tahap 4 — Recovery

PR membuat:

* konten pelayanan baru,
* edukasi staf,
* komunikasi publik yang lebih terbuka.

---

# Pelajaran Penting

Dalam krisis:

```text id="mbpl3y"
Kecepatan respon sangat menentukan reputasi.
```

# 14. Etika Komunikasi dalam Islam

Sebagai mahasiswa KPI, penting memahami bahwa komunikasi harus sesuai nilai Islam.

---

# Prinsip Komunikasi Islam

| Prinsip        | Makna                |
| -------------- | -------------------- |
| Qaulan Sadida  | perkataan benar      |
| Qaulan Layyina | perkataan lembut     |
| Qaulan Baligha | komunikasi efektif   |
| Tabayyun       | verifikasi informasi |

---

# Relevansi dalam Crisis Management

Saat krisis:
- jangan menyebarkan hoaks
- verifikasi informasi
- hindari provokasi
- gunakan bahasa santun

---

# Contoh

Jika ada berita viral:

- ❌ langsung menyebarkan tanpa cek
- ✅ melakukan tabayyun terlebih dahulu
